# duckprompts v0.2 — منصة خطط المحتوى لصنّاع المحتوى

صانع المحتوى يفتح بروفايل لكل عميل ← العميل يملأ فورم (كتابة أو صوت) ← استراتيجية براند ← خطة شهر (20–30 فكرة حسب الموسم والسوق) ← اختيار ← صياغة بالصيغة المطلوبة ← كالندر شهري يراجعه العميل بلينك (موافق ✓ / تعديل ✎ / مرفوض ✕).

الحساب بالكريديت. في التجربة الأدمن هو من يمنح الرصيد (لا يوجد دفع حقيقي).

## التشغيل المحلي
```bash
npm install
cp .env.example .env        # ضع GEMINI_API_KEY، أو AI_PROVIDER=stub لتجربة الواجهة بدون مفتاح
npm run dev                  # الواجهة على :5173 والسيرفر على :3000
```
حسابات التطوير: `admin@duck.test / admin12345` و `creator@duck.test / creator12345`.
في الإنتاج كلمات المرور تؤخذ من `ADMIN_PASSWORD` و `DEMO_PASSWORD` (أو تُولَّد وتُطبع مرة واحدة في اللوج).

## النشر للتجربة (Render + Postgres مجاني)
1. **مفتاح الذكاء الاصطناعي:** يعمل Gemini وGroq معًا (يجرّب بالترتيب في `AI_PROVIDER`، الافتراضي `gemini,groq`). مفتاح Groq مجاني من https://console.groq.com ويوضع في `GROQ_API_KEY`.
   **مفتاح Gemini:** من https://aistudio.google.com/apikey (طبقة مجانية بحدود طلبات). اشتراك Google AI Pro لا يعطي حصة API عادةً، المفتاح منفصل.
2. **قاعدة البيانات:** أنشئ مشروعًا مجانيًا في Neon أو Supabase وانسخ `DATABASE_URL`. بدونها ستُفقد البيانات عند كل إعادة نشر على Render المجاني.
3. **Render:** New → Blueprint → اختر هذا الريبو (يقرأ `render.yaml`). أضف المتغيرين `GEMINI_API_KEY` و `DATABASE_URL`. كلمتا مرور الأدمن والتجربة تُولَّدان تلقائيًا وتجدهما في Environment.
4. الموقع المجاني ينام بعد فترة خمول ويستيقظ ببطء.

## أين البرومتات؟
- **الملفات الافتراضية:** `server/prompts/defaults/*.md` (استراتيجية، خطة الشهر، كتابة المحتوى، الفورم من الصوت).
- **أثناء التشغيل:** لوحة الأدمن ← «البرومتات»: تعديل، نسخ، تفعيل، رجوع. كل تشغيل يسجّل رقم النسخة المستخدمة (سجل التشغيل).
- **شكل المخرجات (JSON)** يُضاف من الكود (`server/prompts.ts → OUTPUT_CONTRACT`) فلا يكسره تعديل البرومبت.

## قاعدة المواسم
لوحة الأدمن ← «المواسم والمناسبات». المناسبات الهجرية تُحسب لكل سنة تلقائيًا (تقويم أم القرى، ±يوم حسب الرؤية). **كل المناسبات المزروعة غير مؤكدة** حتى تراجعها أنت، والموديل يُخبَر بذلك فينبّه صانع المحتوى.

## ضوابط فترة التجربة
- طابور بحد تزامن `AI_CONCURRENCY` ومحاولتا إعادة عند 429.
- حد يومي لكل مستخدم `DAILY_RUN_CAP_PER_USER`.
- لا يُخصم كريديت إلا عند نجاح التوليد، والفاشل يُسجَّل للمراجعة.
- **الخصوصية:** على الطبقة المجانية قد تستخدم Google المدخلات لتحسين خدماتها حسب شروطها. استخدم بيانات تجريبية أو غير حساسة حتى الانتقال لمفتاح مدفوع.

## تبديل المزوّد لاحقًا
الاتصال بالموديل في ملف واحد: `server/ai/provider.ts`. أضف مزوّدًا (Claude/OpenAI) يطبّق `generate()` وبدّل `getProvider()`.

## الأمان (الحالي)
كلمات المرور بـ scrypt، جلسات HttpOnly، تحديد محاولات الدخول، روابط العميل رموز عشوائية طويلة (يمكن إيقاف رابط الكالندر أو تغيير رابط الفورم)، عزل بيانات كل صانع محتوى بالاختبارات. لا يوجد: دفع حقيقي، استعادة كلمة المرور بالبريد، نشر تلقائي على السوشيال.
